# ML Foundations From Scratch

A hands-on collection of Machine Learning implementations and experiments using Python, NumPy, and popular ML libraries. This repository focuses on understanding core concepts through practical coding, data preprocessing, model training, and evaluation.

## Projects

- **Linear Regression with NumPy** — Implementing linear regression using vectorized operations.
- **Logistic Regression** — Exploring classification and feature scaling with `StandardScaler`.
- **K-Means Clustering** — Implementing unsupervised learning using pure NumPy.
- **Machine Learning Pipeline** — Working with messy data, Random Forest, XGBoost, and SHAP for model interpretation.

## Tech Stack

- Python
- NumPy
- Pandas
- Scikit-learn
- XGBoost
- SHAP
- Jupyter Notebook

## Goals

- Strengthen Machine Learning fundamentals through hands-on implementation.
- Understand data preprocessing, feature scaling, and model training.
- Explore supervised and unsupervised learning algorithms.
- Practice model interpretation and data-driven problem-solving.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/zk025815-beep/ML-Foundations-From-Scratch.git
cd ML-Foundations-From-Scratch
```

Install the required libraries:

```bash
pip install numpy pandas scikit-learn matplotlib seaborn xgboost shap jupyter
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open any notebook to explore the implementation and run the code.
